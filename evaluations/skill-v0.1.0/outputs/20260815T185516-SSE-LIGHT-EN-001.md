# Projected final answer — `SSE-LIGHT-EN-001`

> Same-owner projected artifact. Private raw JSONL and tool traces are omitted.

In MCP `2025-06-18`, SSE is optional for streaming a POST request’s response and for server-to-client messaging via GET; sessions and resumability may accompany it when genuinely implemented. Ordinary requests may instead return `application/json`, so SSE is not mandatory.

The bundled `2026-07-28` profile makes each request stateless and self-describing through body `_meta`, with no `initialize` lifecycle or `Mcp-Session-Id`. SSE remains relevant only as a request-scoped response stream; general GET streaming becomes `subscriptions/listen`, and SSE resumability with `Last-Event-ID` is removed.
