## Findings

### F-01 — High: untrusted messages control active DOM

[widget.html:7](../fixtures/mcp-app-multi-projection/widget.html#L7) accepts every `message` event and assigns `event.data.html` to `innerHTML`.

This confirms a DOM-integrity and injection defect for any sender able to message the widget. Host sandboxing or CSP might reduce exploitability, but neither validates the data, and neither was executed here.

Recommended disposition: validate `event.source`, expected origin where meaningful, JSON-RPC/message shape, method, correlation, and payload schema; render plain data through `textContent` or an explicitly reviewed sanitizer.

### F-02 — Medium: widget automatically attempts a potentially mutating capability

[widget.html:11](../fixtures/mcp-app-multi-projection/widget.html#L11) calls:

```js
window.openai.callTool("save_card", { source: "widget" })
```

immediately on load, without an in-widget user gesture. The attempt is confirmed; whether it succeeds, prompts for consent, writes data, or is idempotent is unknown because both the host behavior and `save_card` implementation are absent.

### F-03 — Medium: the declared MCP revision is not implemented by this repository

The project declares `2026-07-28`, but no `server/discover`, per-request metadata validation, JSON-RPC classifier, transport, or routing-header handling exists. If `render_card()` is emitted verbatim as a result, it also lacks the profile’s required `resultType: "complete"` and server identity metadata.

Broader conformance is therefore unknown—not established by the version declaration. Direct emission of this dictionary appears inconsistent with the bundled dated profile.

### F-04 — Medium: UI resource and CSP contracts are declarations without an enforcement path

`ui://thinking-card/v1` and `ui/csp` are returned in `_meta`, but the repository exposes no resource registration connecting that URI to `widget.html`. Media type, cache/version resolution, sandbox creation, and CSP enforcement are all unknown.

### F-05 — Low: `operator/debugToken` crosses into component metadata

[server.py:11](../fixtures/mcp-app-multi-projection/server.py#L11) places the token beside UI metadata. The `operator/` prefix creates no operator-only authority boundary. In this fixture the value is explicitly synthetic, so there is no demonstrated secret exposure, but the projection is incorrectly named for confidentiality purposes.

### F-06 — Low: input and output budgets are unspecified

`title` has no exposed schema or size limit and is copied into both `content` and `structuredContent`. The function itself is deterministic and effect-free for ordinary decoded values, but transport-level parsing, output-size limits, cancellation, and backpressure are absent.
