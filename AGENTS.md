# Historical repository contract

This repository preserves the standalone MCP Server Engineering Field Guide
`2.0.1` release, its provenance, and its evaluation evidence. Continued Guide
development and the active installable skill live in
[`IndelibleVivi/mcp-boundary`](https://github.com/IndelibleVivi/mcp-boundary):
the maintained Guide is under `guide/`, and `src/skills/mcp-boundary/` is the
active skill source.

Do not add new Guide features, protocol profiles, installation guidance, or
release work here. Route those changes to MCP Boundary. Changes in this
repository should be limited to correcting its historical record, preserving
release accessibility, or maintaining the migration pointer, with the existing
bilingual, provenance, evidence, and licensing boundaries kept intact.

The local `skill/mcp-server-engineering/` tree is historical release and
evaluation material. Do not present it as the current installation path. The
general repository-method project formerly named Softpowers is now Servotab.

Do not commit private continuity, raw private evaluations, local paths,
unsanitized logs, credentials, or account data. Repository edits do not
authorize publication, release, visibility changes, history rewriting, or
external account actions.
